# Agent Instructions - BigProjects BOS

This repository is only for BigProjects BOS.

## Do Not Mix Products

Do not implement or document ToonExpo product modules here except integration summaries/contracts.

Not allowed in this repo:

- ToonExpo public web/app;
- buyer/visitor account area;
- builder portal;
- constructor CRM sales workflows;
- builder readiness scoring UI;
- QR scanner/check-in UI;
- public projects/apartments catalog.

Allowed in this repo:

- BOS internal CRM/deals;
- BOS tasks/processes;
- BOS staff/team KPI;
- BOS participant onboarding;
- BOS analytics/reports;
- BOS account provisioning integration with ToonExpo.

## Integration Boundary

BOS can consume summaries from ToonExpo.

ToonExpo remains the source of truth for ToonExpo product data.
