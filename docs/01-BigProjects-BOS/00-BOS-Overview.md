# BigProjects BOS Overview

## Definition

BigProjects BOS is the internal Business Operating System for BigProjects.

It is not ToonExpo.com. It is not the constructor CRM. It is not the public buyer platform.

## Main Goal

BigProjects BOS helps the BigProjects team manage internal work around sales, deals, participants, tasks, processes, KPIs, onboarding, and reports.

## Key Boundary

BOS may show ToonExpo summaries, but it should not become the place where public ToonExpo content, constructor sales CRM, or builder readiness are managed directly.
