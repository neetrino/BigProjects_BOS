Draft

## Recommended Main Navigation

```text
Dashboard
Event Cycles
CRM / Deals
Tasks & Processes
Staff / KPI
Reports
ToonExpo Provisioning
Settings
```

Deal Onboarding Checklist is not a separate main navigation product in v1. It appears inside Deal sheets, in reports, and in admin/settings for template management.

## UI Principle

BOS should be dense, operational, and fast to scan.

Do not make it look like a public marketing site. It is an internal operations tool.
