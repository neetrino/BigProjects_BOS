# BOS Dashboard UX

## Purpose

The dashboard should give BigProjects managers fast operational visibility.

## Widgets

- active deals;
- approved participants;
- onboarding progress;
- open tasks;
- blocked tasks;
- team KPI;
- ToonExpo account provisioning status;
- failed ToonExpo account creation requests.

## UX Rules

- dense and scannable;
- no marketing-style hero sections;
- quick links to filtered lists;
- show blocked/risky work clearly;
- avoid decorative charts that do not support decisions.
