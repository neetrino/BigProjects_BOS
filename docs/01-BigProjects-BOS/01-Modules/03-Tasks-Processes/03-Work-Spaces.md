# Work Spaces

## Definition

Work Space is an organizational/visual container for tasks.

It is not a separate task system.

The same task entity can be visible:

- in Global Tasks;
- in its Work Space;
- in a related deal/company/cycle context.

## Purpose

Work Spaces help teams work by direction/topic.

Examples:

- Marketing;
- Legal;
- Booth Design;
- Technical Materials;
- SMM;
- Certificates;
- Internal Operations;
- Sponsor Materials;
- Event Reporting.

## Unlimited Workspaces

BOS should allow creating as many workspaces as needed.

Departments can have:

- one workspace;
- multiple workspaces;
- temporary event-specific workspace;
- archived old workspace.

## Workspace Page

Recommended workspace sections:

- workspace dashboard/summary;
- board view;
- list view;
- members/responsible users;
- filters;
- settings.

## Workspace Card/Label

Task cards should show workspace label when viewed from global tasks.

Inside a workspace board, the label may be hidden because the context is obvious.

## Workspace Status

Recommended statuses:

```text
active
archived
disabled
```

Archived workspace hides from default navigation but keeps task history.

Disabled workspace cannot receive new tasks unless re-enabled.

## Workspace And Cycle Are Different

Work Space answers:

```text
Which work direction/topic?
```

Event Cycle answers:

```text
Which ToonExpo iteration?
```

A task can belong to both.

Example:

```text
Workspace: Marketing
Cycle: ToonExpo 2026-1
Task: Prepare campaign posts for participant announcement
```
