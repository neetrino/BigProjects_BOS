# Global Tasks Area

## Purpose

Global Tasks is the main place to see all tasks across BOS.

It should help managers answer:

- what is open;
- what is blocked;
- what is overdue;
- what belongs to me;
- what belongs to a cycle/deal/workspace.

## Main Views

Recommended v1 views:

```text
All Tasks
My Tasks
Board
List
Blocked
Overdue
```

Board and List are presentation modes over the same task data.

## Filters

Recommended filters:

- status;
- assignee;
- workspace;
- event cycle;
- related company;
- related deal;
- priority;
- due date;
- blocked only.

## Board Columns

Recommended statuses:

```text
todo
in_progress
blocked
done
cancelled
```

Active board can show:

```text
todo
in_progress
blocked
```

Closed scope can show:

```text
done
cancelled
```

## List Columns

Recommended list columns:

- title;
- status;
- assignee;
- workspace;
- event cycle;
- related entity;
- priority;
- due date;
- created date;
- last activity.

## Task Creation

Task can be created from:

- global tasks page;
- workspace page;
- deal sheet;
- company sheet;
- onboarding checklist item if needed;
- process template/instance.

If created from context, prefill related entity fields.
