# Definition And Boundaries

## Definition

Tasks & Processes is the shared BOS module for internal work execution.

It answers:

```text
What needs to be done, who is responsible, where does it belong, and what is its status?
```

## Two Layers

The task system has two layers:

```text
1. Global Tasks area
2. Work Spaces by direction/topic
```

Global Tasks shows all tasks across the organization.

Work Spaces show focused task sets by direction such as Marketing, Legal, Booth Design, SMM or Technical Materials.

## In Scope

- task creation and editing;
- global task board/list;
- workspaces;
- workspace board/list;
- task status;
- assignee/responsible user;
- due dates;
- priority;
- comments/notes;
- attachments;
- links to cycle/deal/company/onboarding item;
- process templates;
- process instances;
- reporting/KPI inputs.

## Out Of Scope In v1

- separate internal messenger;
- heavy project management suite;
- separate files/documents module;
- complex automation engine;
- time tracking;
- billing from tasks;
- full approval workflow;
- separate Expo Operations module.

## Event Operations Boundary

Event preparation work can be represented through workspaces and tasks.

Examples:

- Booth Design workspace;
- Marketing workspace;
- Technical Materials workspace;
- Legal workspace;
- Certificates workspace.

Do not create a separate Event Operations module in v1 unless a clear large workflow appears later.

## Onboarding Boundary

Deal Onboarding Checklist remains inside deal sheet.

Use tasks only when an onboarding item becomes broader work that needs normal task management.
