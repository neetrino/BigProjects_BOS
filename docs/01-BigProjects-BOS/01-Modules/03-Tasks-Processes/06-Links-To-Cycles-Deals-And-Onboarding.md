# Links To Cycles Deals And Onboarding

## Purpose

Tasks should connect to business context without duplicating other modules.

## Link To Event Cycle

A task can be linked to an event cycle when it belongs to a specific ToonExpo iteration.

Examples:

- prepare marketing plan for ToonExpo 2026-1;
- finalize booth layout for current cycle;
- collect participant materials for cycle.

## Link To Deal

A task can be linked to a deal when it supports one participant process.

Examples:

- call primary contact;
- request missing contract;
- confirm payment proof;
- prepare account provisioning.

Linked tasks can appear in deal sheet.

## Link To Company

A task can be linked to a company when it is not cycle-specific or deal-specific.

Examples:

- update company contact data;
- verify long-term partner information.

## Link To Onboarding Checklist Item

Checklist item can optionally create/link a task if the work is larger than a checkbox.

Examples:

- collect a complex media package;
- coordinate legal correction;
- solve blocked account provisioning issue.

V1 rule:

- standard onboarding remains checklist;
- larger work can become a linked task.

## Avoid Duplication

Do not create separate task lists inside each module.

Instead:

- use one task entity;
- link it to context;
- show it in relevant sheets/views.
