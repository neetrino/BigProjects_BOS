# Dashboard Layout

## Recommended Layout

V1 dashboard can use this structure:

1. header with current cycle selector;
2. key metric cards;
3. CRM/deals summary;
4. onboarding/provisioning summary;
5. tasks/processes summary;
6. KPI/team summary;
7. risks/attention list;
8. quick links.

## Header

Header should show:

- current event cycle;
- date range;
- status;
- cycle switcher;
- last updated time if useful.

## Metric Cards

Metric cards should be small, dense and clickable.

Recommended cards:

- active deals;
- approved participants;
- onboarding completion;
- blocked checklist items;
- open tasks;
- blocked/overdue tasks;
- pending ToonExpo provisioning;
- team workload.

## Risks / Attention

Show important operational risks:

- overdue tasks;
- blocked onboarding items;
- deals stuck in status;
- provisioning failures;
- cycle with no active owner;
- missing active cycle.

## Quick Links

Quick links:

- open CRM board;
- create deal;
- open tasks;
- open cycle reports;
- open provisioning worklist;
- open checklist template settings.

## Mobile

Dashboard should be readable on mobile.

Cards can stack vertically. Tables/lists should become compact rows.
