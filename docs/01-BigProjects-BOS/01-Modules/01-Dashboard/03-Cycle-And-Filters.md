# Cycle And Filters

## Current Cycle Default

Dashboard defaults to current active event cycle.

If no active cycle exists, dashboard should show a clear empty/warning state:

```text
No active ToonExpo cycle selected.
Create or activate a cycle to start operational tracking.
```

## Cycle Selector

Cycle selector should allow:

- current active cycle;
- other active/planning cycles;
- completed cycles;
- archived cycles through advanced/history filter.

## Global Filters

Recommended filters:

- event cycle;
- responsible manager;
- team/workspace;
- date range;
- company type.

Filters should update dashboard widgets consistently.

## Historical Mode

When viewing completed/archived cycle:

- show historical state;
- hide or disable active work prompts;
- link to reports/comparison;
- make it clear the user is not viewing current cycle.

## All Cycles Mode

All Cycles mode can be useful for management, but default should remain current cycle.

All Cycles widgets must show cycle labels where needed to avoid confusion.
