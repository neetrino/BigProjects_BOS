# Acceptance Criteria

## General

- [ ] Dashboard opens as main BOS overview.
- [ ] Dashboard defaults to current active cycle.
- [ ] Dashboard shows a clear empty state if no active cycle exists.
- [ ] Dashboard widgets link to source module filtered views.

## Metrics

- [ ] Dashboard shows CRM/deal summary.
- [ ] Dashboard shows participant/onboarding summary.
- [ ] Dashboard shows task/process summary.
- [ ] Dashboard shows provisioning summary.
- [ ] Dashboard shows KPI/team summary if user has permission.

## Filters

- [ ] User can switch cycle.
- [ ] Historical cycles show historical mode.
- [ ] Filters apply consistently to widgets.

## Permissions

- [ ] Dashboard respects source module permissions.
- [ ] BOS Viewer cannot edit from dashboard.
- [ ] Staff users see assigned/allowed work according to role.

## Boundaries

- [ ] Dashboard does not edit Constructor CRM data.
- [ ] Dashboard does not duplicate full reports module.
- [ ] Dashboard does not become a file/document archive.
