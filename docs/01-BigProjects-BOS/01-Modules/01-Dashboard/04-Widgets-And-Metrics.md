# Widgets And Metrics

## CRM Metrics

Recommended:

- deals total in selected cycle;
- deals by status;
- approved participants;
- lost/cancelled deals;
- contract pending count;
- payment pending/overdue count if tracked.

## Onboarding Metrics

Recommended:

- checklist completion percent;
- completed checklist items;
- open checklist items;
- blocked checklist items;
- deals with outdated checklist template;
- deals missing required onboarding items.

## Task Metrics

Recommended:

- open tasks;
- my tasks;
- blocked tasks;
- overdue tasks;
- tasks by workspace;
- tasks by assignee.

## Provisioning Metrics

Recommended:

- pending provisioning requests;
- successful provisioned accounts;
- failed provisioning requests;
- manual action required.

## KPI Metrics

Recommended:

- team completion summary;
- manager assigned deals;
- tasks completed by user;
- blocked work by user;
- onboarding completion by responsible manager.

## Widget Rules

- every widget should have a source module;
- every actionable widget should link to filtered source view;
- avoid decorative metrics that do not help decisions;
- keep calculations understandable.
