# Cycle Comparison Reports

## Purpose

ToonExpo repeats multiple times per year, so cycle comparison is a core reporting need.

## Comparison Questions

Reports should answer:

- how many companies participated in each cycle;
- how many deals were created;
- how many deals became approved participants;
- how many were lost/cancelled;
- which managers handled more deals;
- how onboarding completion changed;
- which checklist categories caused delays;
- how task load changed between cycles;
- how many ToonExpo accounts were provisioned.

## Required Filters

- cycle;
- compare with cycle;
- year;
- responsible manager;
- company type;
- deal status.

## Comparison Table

Recommended columns:

- cycle name;
- date range;
- total deals;
- approved participants;
- lost/cancelled;
- onboarding completion percent;
- blocked checklist items;
- open tasks;
- completed tasks;
- provisioning success/failure.

## Historical Integrity

Completed/archived cycles must remain reportable.

Do not delete cycles with deals/history.

## v1 Simplicity

Practical tables and simple charts are enough:

- bar chart by cycle;
- status breakdown;
- summary cards;
- filtered table.

Advanced forecasting and BI modeling can come later.
