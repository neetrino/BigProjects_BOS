# Acceptance Criteria

## Reports

- [ ] User can view cycle reports.
- [ ] User can view CRM/deal reports.
- [ ] User can view onboarding reports.
- [ ] User can view task/process reports.
- [ ] User can view staff KPI reports if permitted.
- [ ] User can view provisioning reports.

## Cycle Comparison

- [ ] Reports can filter by event cycle.
- [ ] Reports can compare cycles.
- [ ] Completed/archived cycles remain reportable.

## Drilldown

- [ ] Report rows/widgets link to filtered source views.
- [ ] Deal metrics link to CRM.
- [ ] Task metrics link to Tasks.
- [ ] Onboarding metrics link to deal/onboarding views.
- [ ] Provisioning metrics link to the provisioning worklist.

## Permissions

- [ ] Reports respect source module permissions.
- [ ] Exports respect user permissions.
- [ ] Sensitive exports can be audited if implemented.

## Boundaries

- [ ] Reports do not edit operational data.
- [ ] Reports do not require full ToonExpo public/buyer data sync.
- [ ] V1 does not require heavy BI warehouse.
