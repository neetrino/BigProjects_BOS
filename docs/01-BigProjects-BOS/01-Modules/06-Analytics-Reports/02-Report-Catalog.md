# Report Catalog

## Cycle Reports

Reports:

- current cycle overview;
- cycle comparison;
- participant count by cycle;
- deals by status and cycle;
- onboarding completion by cycle;
- task load by cycle.

## CRM / Deal Reports

Reports:

- deals by status;
- deals by responsible manager;
- approved participants;
- lost/cancelled reasons;
- contract status;
- payment status if tracked;
- deal value if tracked.

## Onboarding Reports

Reports:

- checklist completion by deal;
- checklist completion by manager;
- blocked checklist items;
- outdated checklist template usage;
- checklist category completion;
- average onboarding completion time if timestamps exist.

## Task / Process Reports

Reports:

- tasks by status;
- tasks by workspace;
- tasks by assignee;
- overdue tasks;
- blocked tasks;
- process instance progress.

## Staff KPI Reports

Reports:

- assigned deals by manager;
- approved participant count by manager;
- completed tasks by user;
- blocked work by user;
- onboarding item completion by user;
- workload summary.

## Provisioning Reports

Reports:

- pending provisioning requests;
- successful provisioned accounts;
- failed provisioning requests;
- manual action required;
- provisioning by cycle.

## Export

Optional exports:

- CSV;
- XLSX if needed later;
- filtered report export.

Export should respect user permissions.
