# Exports Permissions And Privacy

## Permissions

Reports must respect source module permissions.

If a user cannot see a deal/task/company in source modules, they should not be able to export it from reports.

## Role Access

Recommended:

- BOS Admin: all reports and exports;
- BOS Staff: assigned/allowed operational reports;
- BOS Viewer: read-only reports, export only if allowed.

## Export Rules

Optional v1 export formats:

- CSV;
- XLSX later if needed.

Export should include:

- report name;
- filters used;
- generated at;
- generated by.

## Privacy

BOS reports are internal.

Do not export buyer/visitor personal data from ToonExpo in v1 because BOS does not sync Constructor CRM/buyer data.

Reports can include company/contact data that belongs to BOS CRM, according to permissions.

## Audit

If exports contain sensitive company/contact data, log:

- user id;
- report key;
- filters;
- export format;
- timestamp.
