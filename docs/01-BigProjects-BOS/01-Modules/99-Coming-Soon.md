# BOS Coming Soon Modules

## Status

Coming soon / not separate v1 modules

These modules can be planned for the future, but should not be built as separate modules in the first version.

## Separate Expo Operations Module

This would be a dedicated module for managing the physical expo event:

- hall/venue plan;
- booth/stand placement;
- booth assembling;
- badges;
- certificates;
- LED/video materials;
- technical questionnaires;
- event checklists.

v1 decision:

```text
Do not build separate Expo Operations module.
Cover this through Tasks & Processes.
```

## Separate Internal Communication Module

This would be an internal chat/communication area:

- internal messages;
- mentions;
- threads;
- support tickets;
- team discussions.

v1 decision:

```text
Do not build separate communication module.
Use comments/notes inside company, deal, task and process cards.
```

## Separate Files / Documents Module

This would be a standalone document archive:

- folders;
- document library;
- global search;
- file permissions;
- file versioning.

v1 decision:

```text
Do not build separate Files/Documents module.
Attach files/documents to the relevant entity cards.
```
