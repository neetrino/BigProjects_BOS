# Event Cycles

## Status

Release 1 canonical module.

## Purpose

EventCycle is the operational container for one ToonExpo iteration. Organizations and Contacts persist across cycles; BuilderDeal, PartnerParticipation, VenuePlan, SpaceAllocation, provisioning and publication history are cycle-specific.

Release 1 permits several `active` cycles during overlap but zero or one explicitly current cycle. A cycle can have at most one VenuePlan.
