# Deal Onboarding Checklist - Module Index

## Delivery Status

Later product phase. Builder Sales Release 1 does not create checklist templates or checklist instances.

## Purpose

Deal Onboarding Checklist is the simple checklist inside each BOS participant deal.

It helps BigProjects managers track what must be done before and after a company becomes a ToonExpo participant.

## Future Module Rules

- Checklist belongs to a deal.
- Deal belongs to an event cycle.
- Checklist is not a separate onboarding platform.
- Checklist is not the same as the general Tasks module.
- New deals receive a snapshot of the latest active checklist template.
- Existing active deals are updated from the latest template only through a manual action.
- Completed/lost/cancelled deals are not automatically updated.
- Checklist changes must keep completed items, notes, attachments and responsible users.
