# Acceptance Criteria

## Template

- [ ] BOS Admin can manage onboarding checklist template.
- [ ] Template supports draft, active and archived statuses.
- [ ] New deal receives latest active checklist template.
- [ ] Template item order and categories are preserved in deal checklist.
- [ ] Old templates remain available for audit/history.

## Deal Checklist

- [ ] Deal sheet shows onboarding progress.
- [ ] Manager can check/uncheck checklist items.
- [ ] Manager can mark item blocked or not applicable if needed.
- [ ] Completed item stores completed by and completed at.
- [ ] Item notes/attachments can be saved.
- [ ] Checklist remains inside deal sheet, not a separate onboarding platform.

## Template Updates

- [ ] Existing active deals do not update automatically in the background.
- [ ] Eligible active deals can be manually updated from latest template.
- [ ] Update preview shows added and legacy/removed items.
- [ ] Applying update keeps completed items, notes, attachments and responsible users.
- [ ] Removed template items become archived/legacy, not deleted automatically.
- [ ] Update action writes audit log.

## Boundaries

- [ ] Checklist does not duplicate Tasks module.
- [ ] Checklist does not duplicate ToonExpo readiness scoring.
- [ ] Checklist can include ToonExpo account provisioning item.
- [ ] Checklist is cycle-specific through its deal.
