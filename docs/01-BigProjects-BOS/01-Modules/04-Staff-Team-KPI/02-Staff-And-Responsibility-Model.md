# Staff And Responsibility Model

## Staff User

Staff user is a BOS internal user.

Recommended simple roles:

- BOS Admin;
- BOS Staff;
- BOS Viewer.

Additional team labels/departments can exist as metadata.

## Responsibility Sources

User can be responsible for:

- company;
- deal;
- task;
- onboarding checklist item;
- workspace;
- provisioning request.

## Assignment Rule

Each operational record should have one primary responsible user where useful.

Examples:

- deal responsible manager;
- task assignee;
- onboarding item responsible user;
- workspace owner.

## Team / Department

Team/department can be simple metadata:

- Sales;
- Marketing;
- Legal;
- Operations;
- Management.

Do not build complex HR hierarchy in v1.

## Workload View

Staff profile should show:

- active deals;
- approved participant deals;
- open tasks;
- overdue tasks;
- blocked tasks;
- onboarding items assigned;
- provisioning requests assigned if used.

## Cycle Context

Staff workload and KPI should be filterable by event cycle.

This matters because team performance should be comparable across ToonExpo iterations.
