# KPI Views And UX

## Main Views

Recommended v1 views:

- Team KPI list;
- Staff profile / KPI detail;
- My work summary;
- Team workload summary;
- KPI reports.

## Team KPI List

List should show:

- staff name;
- team/department;
- active deals;
- approved participants;
- open tasks;
- overdue tasks;
- blocked tasks;
- onboarding completion;
- KPI status.

Clicking a staff row opens staff detail sheet/page.

## Staff Detail

Staff detail should show:

- basic user info;
- role/team;
- assigned deals;
- assigned tasks;
- onboarding items;
- provisioning items if assigned;
- KPI summary;
- filters by cycle/date.

## My Work

Staff user should quickly see:

- my tasks;
- my deals;
- my blocked items;
- my onboarding responsibilities;
- current cycle focus.

## Drilldown

KPI numbers should link to source records.

Examples:

- overdue tasks -> filtered tasks list;
- active deals -> filtered CRM deals;
- blocked onboarding -> filtered deals/checklist items.

## UX Rule

KPI should not shame or confuse users with unexplained scores.

Use clear operational facts first.
