# Acceptance Criteria

## Staff

- [ ] BOS Admin can view staff list.
- [ ] Staff user has role/team/status metadata.
- [ ] Staff detail shows assigned work.
- [ ] Staff workload can be filtered by event cycle.

## KPI

- [ ] KPI reads deals, tasks and onboarding data.
- [ ] KPI shows open/completed/blocked work.
- [ ] KPI shows approved participant count by responsible manager.
- [ ] KPI metrics link to source records.
- [ ] KPI status is understandable.

## Permissions

- [ ] BOS Admin can see full team KPI.
- [ ] BOS Staff can see own/allowed work.
- [ ] BOS Viewer is read-only if allowed.
- [ ] KPI is not visible to ToonExpo external users.

## Boundaries

- [ ] KPI does not calculate payroll/bonuses in v1.
- [ ] KPI does not duplicate source records.
- [ ] KPI does not require complex HR module.
