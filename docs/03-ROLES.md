# Roles And Permissions

Release 1 has only two roles.

## Admin

Admin can:

- create and disable staff accounts;
- manage event cycles;
- manage all organizations and contacts;
- manage both Kanban boards;
- upload and calibrate a venue plan;
- create, edit and delete free map areas;
- assign and release areas;
- request ToonExpo accounts;
- publish the public map.

## Staff

Staff can:

- view active event cycles;
- manage organizations and contacts;
- create and update builder deals;
- create and update partner records;
- add notes and attachments;
- create and edit free map areas;
- assign and release areas;
- request ToonExpo account creation.

Staff cannot:

- manage users;
- close an event cycle;
- publish the public map;
- change global settings.

## Rule

Do not introduce Viewer, Manager, Sales Manager, Map Editor or configurable permission sets in Release 1. Add another role only after a real access problem appears.
