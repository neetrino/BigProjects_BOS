# BOS MVP Scope Freeze

## Included In v1

- internal auth and roles;
- event cycles;
- internal company/contact/deal CRM;
- deal onboarding checklist template and deal checklist instance;
- tasks and configurable workspaces;
- staff/team KPI summaries;
- dashboard widgets;
- analytics/reports;
- ToonExpo account provisioning queue/status;
- entity notes and attachments.

## Explicitly Out Of Scope

- ToonExpo public website/app;
- builder portal;
- Constructor CRM;
- builder readiness scoring;
- QR/check-in implementation;
- full ToonExpo data sync;
- separate files/documents module;
- separate event operations module;
- payroll/HR system;
- payments/accounting integration.

## v1 Success Definition

BigProjects can run one ToonExpo cycle internally from participant deal creation through approval, onboarding checklist progress, task coordination and ToonExpo account provisioning.
